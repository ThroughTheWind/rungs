# 0.5.0 — unreleased

- **`eject` keeps its promise.** The ejected runner is now one esbuild bundle carrying every engine
  and every runtime dependency, copied from `dist/ejected-runner.mjs`; gate tables are frozen as
  parameter-substituted JSON and the raw module metadata the meta-gates read is materialised beside
  them. `.ai/rungs.mjs` becomes a local forwarder that runs the bundle with `process.execPath`, so
  `node .ai/rungs.mjs check [tier]` works with no npm, no package and no rungs checkout, with the same
  tiers, output, ledger fields and exit codes as the CLI. A repeat eject is byte-idempotent, and an
  edited launcher or a foreign `.rungs/` directory refuses the whole operation before anything is
  written. (WI-077, closes F-042 and F-045)
