# 0.5.0 — unreleased

- **`eject` keeps its promise.** The ejected runner is now one esbuild bundle carrying every engine
  and every runtime dependency, copied from `dist/ejected-runner.mjs`; gate tables are frozen as
  parameter-substituted JSON and the raw module metadata the meta-gates read is materialised beside
  them. `.ai/rungs.mjs` becomes a local forwarder that runs the bundle with `process.execPath`, so
  `node .ai/rungs.mjs check [tier]` works with no npm, no package and no rungs checkout, with the same
  tiers, output, ledger fields and exit codes as the CLI. A repeat eject is byte-idempotent, and an
  edited launcher or a foreign `.rungs/` directory refuses the whole operation before anything is
  written. (WI-077, closes F-042 and F-045)
- **The shell-safety hook reaches consumers.** `instructions-shell-backticks` now has an engine
  (`shell-safety`), a dispatch command (`rungs hook <gate-id>`: exit 2 blocks, 0 permits, 1 never
  blocks), and a delivery path: installing or upgrading `instructions` into a repo whose harness
  matrix includes `claude` merges one `PreToolUse` entry into `.claude/settings.json` naming the
  pinned launcher, preserving everything already there and adding nothing on a repeat; every other
  harness gets a degradation row in `.ai/render-report.md`. The four shipped fixtures execute, and
  the ejected launcher retains `hook` so the entry keeps working after ejection.
  (WI-086, ADR-0010, closes F-054; `instructions` 1.2.0 → 1.3.0)
- **Every shipped self-test fixture executes.** 146 of 148 fixtures across all fifteen modules now
  run through their real engine (the two that cannot name the unimplemented rule they would need),
  and an engine that throws on its own fixture is a gate failure rather than a coverage gap.
  Running them implemented the table rules nothing had read: `when` and `required_subsections`
  (sections), `field_shape` (frontmatter), `requires_note` (registers), `exempt_marker` and
  structural `similarity` (populations), register-row ids (id-integrity), and index currency plus
  never-rendered detection (render-freshness); `render` now fills a `file-index` block from its
  sources. Three shipped defects fell out: an exemption marker with no reason exempted anyway
  because `-->` counted as a reason, the findings closure gate's row pattern matched no real row, and
  two tables shared one spec entry between two gates so each ran the other's rule. (WI-087)
- **Instruction diagnostics, built the way the oracle allows.** Two detectors join the `instructions`
  module. `instructions-imperatives` is an evidence surface for `doctor --explain` only (a new
  `surface = "explain"` registry form, never run by `check`, never converted at ejection): every line
  of an instruction file that states a rule, with file, line and the modal that matched, and no
  verdict on enforcement in either direction (ADR-0011). Its matcher was shaped by a hand-classified
  oracle written before it existed, which found 70% of a naive grep's hits in the largest corpus file
  to be project history; measured against that oracle it reports 0% false positives on four
  repositories and 15.6% on the fifth. `instructions-stale-commands` is a real gate: `npm|pnpm|yarn
  run <script>` against `package.json` scripts and `rungs <command>` against the CLI's own dispatch
  table, no finding where no surface exists. (WI-061, ADR-0011; `instructions` 1.3.0 → 1.4.0)
- **`fast_budget_ms` is finally read.** Ledger rows now carry ADR-0005's full schema — a per-run
  identifier and the gate's tier beside the date, id, status, wall-clock and examined count — and
  `doctor` reports the first tier's observed serial wall-clock over the last ten recorded runs
  (median, maximum, runs over budget) beside the declared budget. A measurement, never a verdict:
  `check` prints nothing about it and selects nothing by it. A disabled or absent ledger, a history
  under three runs, and rows that predate the fields or do not parse are each named as such. (WI-088,
  closes F-055)
- **`worktrees` never calls an unreadable tree prunable.** A worktree whose status cannot be read —
  its directory gone, for instance — is listed as `status UNKNOWN` with Git's reason, counted as
  "could not be inspected", and withheld from the prunable count. The boolean that turned a failed
  read into "clean" is gone. (WI-089, closes F-057)
- **A fresh decision index passes its own gate.** `adr-index-current` no longer counts the shipped
  template's `— · none yet` placeholder as a listed record, so an untouched scaffold with zero
  decisions passes instead of failing on its first `check`; `render` emits the same placeholder for
  zero sources, so a fresh index and its first render agree byte for byte, and the template block is
  now exactly what `render` writes. Found by the disposable Arena Lab canary at `f4ede793`, which
  failed 1 of 24 gates on both the installed and the ejected surface. (WI-091; `adr` 1.2.0 → 1.2.1)
