# 0.4.0 — pending

Minor. This fragment is reconstructed from the commits after v0.3.1: those changes landed before
Rungs enforced its own per-branch fragment obligation. WI-070 registers that obligation and is the
last change reconstructed here; later release work should amend this file as it lands.

## Added

- Generated repositories use one managed `.ai/rungs.mjs` launcher with an exact `@rungs/cli`
  version. Local instructions and generated CI share it, runtime dependencies are exact, and
  `upgrade --to <exact-version>` provides a bounded bootstrap path for advancing the pin.
- Module provenance can state that work was designed rather than extracted, with a first-person
  rationale instead of invented source incidents.
- The package suite now exercises a packed CLI against an isolated existing Git repository,
  including authority preservation, origin-only stable refs, repeated checks, same-version
  upgrades and rollback.

## Fixed

- Declared module conflicts are enforced symmetrically and propagate through dependency edges;
  an explicit override names what it overruled.
- Fresh generated findings registers pass their own schema instead of treating the visible empty
  placeholder as a malformed finding.
- Backlog branch reconciliation resolves a local stable branch, exact `origin` ref or sole other
  remote-tracking ref deterministically, and fails closed on absence or ambiguity.
- Re-registering an unchanged managed gate block preserves surrounding bytes and line endings, so
  a same-version upgrade leaves both LF and CRLF consumers clean.
- Both release-fragment gates now execute their declared contracts. Shipping-code changes require
  a fragment changed by the same branch or a same-line reasoned exemption, and stale versioned
  fragments reach the production runner through one strict shared table selector.
- Release repositories track the version through which changelog fragments were consumed. The
  freshness gate now rejects a retained fragment equal to that boundary and reconciles it with the
  package version before a tag can be cut.
- Module emission, upgrade and harness rendering now preflight one canonical consumer-repository
  boundary before writing. Portable traversal/absolute forms, outward aliases, unpaired surrogates,
  hard-linked writable leaves, reserved shared-sink impersonation, cross-phase target collisions and
  leaf-symlink ownership redirects fail closed without a partial install or upgrade.
- Release version consistency reads dotted values from JSON and TOML plus the configured XML
  element in `Directory.Build.props`. A matched malformed, missing, invalid or unsupported source
  and a configuration that matches no sources now fail explicitly instead of reporting green from
  incomplete or zero evidence. Repositories can exclude independently versioned manifests with the
  real `release.version_exclude` parameter rather than a module-only test override.
- `rungs land` refuses before locks, gates, scratch worktrees or ref updates when any worktree holds
  the integration branch, and revalidates that invariant immediately before advancing it. It names
  every holding path, parks a verified merge when a holder appears during gates, and preserves clean
  or dirty worktree state. The configured integration name must also match one exact, direct stored
  ref, so case and symbolic aliases cannot redirect an update into a branch held elsewhere.
- `rungs land` now protects the configured green marker and recovery branches with the same exact,
  direct-ref and worktree-holder discipline. Integration and green advance in one no-dereference,
  expected-old transaction or neither is written by Rungs. Refusals create or reuse a collision-free
  recovery branch without overwriting distinct work, and successful lands retain every recovery ref
  for explicit operator cleanup. Dangling symbolic refs omitted by normal Git enumeration are still
  detected across files and reftable repositories rather than being replaced as if absent, and a
  dangling worktree branch that differs only by a Windows/APFS storage alias still blocks the
  colliding managed or recovery ref. Git versions predating the ref-format query keep using the
  files scanner even when `rev-parse` echoes the unknown option with a successful exit.
- `rungs land` now proves inherited red against a clean detached invoking checkout at the exact
  integration commit. A command gate that passes with the checkout's ignored runtime but fails in
  both dependency-less scratch states is reported as unverified and cannot advance integration or
  green; command failures retain normalized exit status and full stderr/stdout for diagnosis.
- `rungs backlog archive` validates its configured root, move sources and destinations, and every
  Markdown rewrite as one contained mutation set before writing. Traversal, outward aliases,
  occupied destinations, non-files, hard-linked rewrite leaves, and forged or stale plans now fail
  closed; valid inward aliases keep their existing archive behavior.
