# 0.3.1 — pending

Patch. Every change is a fix, and all of them are the same class: **code that had never run outside
Windows, in gates whose job is telling a repo the truth about itself.** 0.3.0 shipped with these
because it was published on a red build (F-035); this is the release that reads the build first.

Reconstructed from commits rather than accumulated as fragments — the fixes landed without one.
`release-changelog-fragment` exists for exactly that and is not registered in this repo, which is
now the strongest argument for registering it.

## Fixed

- **`backlog-merged-status` had never worked on Linux or macOS** (F-033). It ran
  `git branch --merged <branch> --format=%(refname:short)` through a **shell**, and unquoted
  parentheses are a bash syntax error — so the command threw, the catch fired, and the gate reported
  *"cannot read git branches; status not reconciled"* as a finding on every non-Windows repo. It
  ships in `backlog`, rung 1, present in **four of five profiles**. Every shell-invoked `git` in the
  engines and in `setup git` is now `execFileSync` with an argv array, which also stops branch names
  and merge-driver names reaching a shell as data.
- **Three more gates, one shared cause** (F-036): `new URL(import.meta.url).pathname.slice(1)`
  strips a leading `/`, which is right for `/C:/…` and turns `/home/…` into a *relative* path
  everywhere else. `loadAllModules` then resolved nothing, so `skills-spec-pure` and
  `skills-description-routes` reported a legitimate module opt-in as a non-spec key, and
  `gates-self-tests-both-directions` reported two gates as having no fixtures when each has four.
- **CRLF checkouts defeated `^…$` anchors in emitted module content** (F-034), so a rule that was
  present read as missing on a Windows checkout with `core.autocrlf=true`. A repo-level
  `.gitattributes` normalises to LF. This does **not** fix a consumer whose own checkout is CRLF —
  `emittedFiles` writes what it reads — and that half stays open in the finding.

## Changed

- rungs runs its own gates in CI across `{ubuntu, macos, windows} × node {22.18, 22}`. Its first
  runs found all four defects above in under a minute; run `32033459743` is the first fully green
  matrix this repository has had.
- `release-runbook.md` §6 now opens with **read the CI run for the commit you are about to tag**.
  Step 2's `rungs check` is local, and a local run is green on exactly one platform. A red run is
  not automatically a stop — not looking is.
